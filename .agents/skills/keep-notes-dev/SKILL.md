# Keep Notes Vault Skill Guidelines

When working on note visual cards or media uploads:
1. Refer to `src/components/NoteCanvas.js` for grid masonry cards, card colors, and pin state.
2. Refer to `src/components/MediaUploader.js` for image preview, audio playback, video, and file link handlers.
3. Ensure color objects adhere to Tailwind keep color palette in `tailwind.config.js`.
